# Weekly Class Schedule

A simple schedule app. Add a class once, choose the days it meets, and it shows up on the grid every week. It runs in any browser and can be packaged as an Android app with Capacitor.

## Features

- Add a class with a name, meeting days, start and end time, and a color
- Classes repeat every week automatically
- Browse previous and next weeks, with the current day highlighted
- Click a class on the grid to edit or delete it
- The grid grows to fit early or late classes
- Works offline, and saves your classes on your device
- Light and dark mode that follows your system setting
- Responsive layout for desktop and phone

## Project structure

```
schedule-app/
├── android/                 Android project (generated by Capacitor)
├── www/
│   ├── index.html           Page structure
│   ├── style.css            Styles and light/dark themes
│   └── script.js            App logic
├── capacitor.config.json    Capacitor settings
└── package.json
web-version/                  Base files for web use
├── index.html                
├── style.css 
└── script.js 
```

If you only want to use the app in a browser, you just need the three files in `web-version`.

## Run in a browser

1. Put `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in your browser.

No build step or server is required.

## Build the Android app

### Requirements

- [Node.js](https://nodejs.org) (current LTS)
- [Android Studio](https://developer.android.com/studio) with the Android SDK installed
- Java 21. Use the JDK bundled with Android Studio (`jbr-21`) rather than a newer system Java

### First-time setup

```bash
mkdir schedule-app && cd schedule-app
npm init -y
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli
npx cap init "Class Schedule" com.yourname.classschedule --web-dir=www
```

Create a `www` folder, copy the three app files into it, then:

```bash
npx cap add android
npx cap sync
npx cap open android
```

Replace `com.yourname.classschedule` with your own unique app id. Choose it before you build, since changing it later is awkward.

### Build the APK

In Android Studio, with the `android` folder open:

1. Set **Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK** to `jbr-21`.
2. Run **File > Sync Project with Gradle Files** and wait for it to finish.
3. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

The debug APK is created at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Or build from the terminal inside the `android` folder:

```bash
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```

### Install on a phone

- **USB:** enable Developer options and USB debugging, connect the phone, and press Run in Android Studio.
- **File:** copy the APK to the phone, open it, and allow installs from that source.

### After changing the code

Edit the files in `www/`, then run:

```bash
npx cap sync
```

and rebuild. Capacitor only copies your files into the Android project when you sync.

## How it works

Each class is stored as data, not as calendar dates:

```js
{
  id: "1718000000000",
  name: "Biology 101",
  days: [0, 2],          // 0 = Monday ... 6 = Sunday
  start: "09:00",
  end: "10:15",
  color: "#3b6fe0"
}
```

When you view any week, the app works out the dates for that week and draws every class whose `days` include each weekday. That's why a class appears in every week without being copied.

The grid is built by `render()` in `script.js`. Each class block is positioned inside its day column using its start time and duration, at 56 pixels per hour. Changing the `classes` array and calling `render()` updates the screen.

Classes are saved in `localStorage` under the key `class-schedule-v1`.

## Customizing

- **Colors:** edit the `COLORS` array in `script.js`
- **Hour height:** change the `HR` constant in `script.js`
- **Default grid hours:** change the `lo` and `hi` starting values in `render()`
- **Theme:** edit the CSS variables at the top of `style.css`
- **Font:** the app loads Bricolage Grotesque from Google Fonts. To work fully offline, download the font files, place them in `www/`, and load them with `@font-face`

## Troubleshooting

| Problem | Fix |
| --- | --- |
| CSS doesn't load | Check the filename is exactly `style.css`, sits next to `index.html`, and isn't `style.css.txt`. Hard refresh with Ctrl+Shift+R |
| "SDK not found" in Android Studio | Install the SDK through **Tools > SDK Manager** |
| "Incompatible Gradle JVM version" | Set the Gradle JDK to `jbr-21` in the Gradle settings |
| `build` folder is empty | Look in `android/app/build/outputs/apk/debug/`, and confirm the build finished without errors |
| Code changes missing in the app | Run `npx cap sync` and rebuild |
| Classes disappeared | They're stored per app and per browser. Clearing site data or uninstalling the app removes them |

## Limitations

- Classes are stored only on the device they were entered on. There's no sync between devices
- Overlapping classes are drawn on top of each other rather than side by side
- Classes repeat weekly with no per-week exceptions
